# Portfolio — Ephraïm AWAGA

Portfolio professionnel en français, conçu pour une consultation sur téléphone ou ordinateur. Il présente RiskSim, CardioAI, ForestIA et une orientation vers la cybersécurité.

Site statique : ouvrir `index.html` ou le servir avec un serveur HTTP local. Aucune installation de dépendances ni compilation nécessaire. Les fiches de projets utilisent les éléments natifs HTML `details` pour rester accessibles sans JavaScript.

## Sources des visuels

- `risksim.webp` : capture du rapport de stage AWAGA, exemple synthétique.
- `cardioai.webp` : capture du dépôt collectif public [CardioAI](https://github.com/Appolinairee/heart-failure-predictor/blob/main/docs/screenshot-dashboard.png).
- `forestia.webp` : photo du prototype en cours d’assemblage, dossier du projet collectif ForestIA.

Les projets collectifs et les limites des prototypes sont indiqués dans les fiches. Les dépôts privés restent privés. Le CV sera ajouté après sa prochaine révision.

## Publication

GitHub Pages : branche `main`, répertoire racine `/`. Le fichier `.nojekyll` permet de servir directement les fichiers statiques.
